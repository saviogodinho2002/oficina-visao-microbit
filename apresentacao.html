Dia 1

Visão computacional

Como o computador acha padrões numa imagem (bordas e filtros) e como ele aprende esses padrões a partir de exemplos. Depois, quatro passos com a webcam: malha, piscadas (duas versões) e emoção.

Uma imagem é uma tabela de números

passe o mouse num pixel
  • Cada quadradinho é um pixel. Em tons de cinza, é um número de 0 (preto) a 255 (branco)
  • Colorido, cada pixel tem 3 números: vermelho, verde e azul (RGB)
  • A webcam em 1280 × 720 manda 921.600 pixels × 3 = 2,7 milhões de números por quadro, umas 30 vezes por segundo
  • "Ver" um rosto, para o computador, é achar um padrão nessa tabela

O problema: achar o olho nessa tabela

Primeira ideia: o olho é escuro, então

if (pixel < 50) {
  // é olho
}
  • Com a luz normal, funciona: marca só os 4 pixels dos olhos
  • Escureça a sala: a pele fica abaixo de 50 e a regra chama o rosto inteiro de olho
  • O número de um pixel sozinho depende da luz. O que continua igual é a diferença entre vizinhos: o olho é bem mais escuro que a pele ao lado dele

O que é uma borda

  • Para cada pixel: vizinho da direita − vizinho da esquerda. Perto de 0: nada muda ali. Número grande (positivo ou negativo): borda, o contorno do rosto, do olho, da boca
  • Escureça: os números da linha mudam, as diferenças não
  • Essa conta tem um nome: aplicar o filtro [−1, 0, +1] (−1 no vizinho da esquerda, 0 no próprio pixel, +1 no da direita)

O filtro faz essa conta na imagem toda

entrada: o rosto (14 × 14)

filtro 3 × 3:

passe o mouse num pixel da saída

saída (12 × 12)

O filtro de borda vertical é a conta do slide anterior em 3 linhas de uma vez: −1 na coluna da esquerda, +1 na da direita, somado. Ele passa por todas as posições e monta uma imagem nova. Passe o mouse na saída para ver a conta. Azul é negativo, laranja é positivo.

O que o filtro resolve

entrada

borda vertical

  1. A luz não atrapalha. Os pesos do filtro somam 0 (três −1 e três +1). Escureça: todos os pixels da entrada mudam, a saída fica igual. Era isso que quebrava a regra pixel < 50.
  2. Acha o padrão em qualquer lugar. Os mesmos 9 números passam pela imagem toda: a saída acende nos dois olhos sem ninguém dizer onde eles ficam.
  3. Usa poucos números. 9 números, reaproveitados em todas as 144 posições da saída. Um modelo que olhasse cada pixel de uma imagem 64 × 64 separadamente precisaria de 4.096 números para cada padrão.
  4. Filtro sobre filtro. Aplicando filtros na saída de outros filtros, bordas viram cantos e curvas, que viram olho e boca. O detector de emoção do passo 4 é isso, com filtros que ninguém escreveu à mão.

Aprender é ajustar um número

Na regra pixel < 50 do slide 5, o 50 foi um chute. E se a máquina achasse esse número sozinha, a partir de exemplos?

  • exemplo rotulado: o valor de um pixel e a resposta certa (olho ou pele)
  • parâmetro: o número que pode mudar; aqui, o limiar da regra
  • erro: quantos exemplos ficam do lado errado
  • treino: a cada passo, ver para que lado o erro diminui e mover o parâmetro um pouco para lá (a "descida do gradiente")

O limiar aprendido erra menos que o chute, mas ainda olha um pixel sozinho: escurecendo a sala, quebra igual. Para isso servem os filtros, e eles também podem ser aprendidos.

Valores inventados para mostrar a ideia.

Um neurônio: multiplicar, somar, cortar o negativo

  • Entradas: 3 pixels (de 0 a 1). Pesos: quanto cada um importa, podem ser negativos
  • Saída: soma dos produtos mais o viés; se der negativo, vira 0 (a função ReLU)
  • O filtro 3 × 3 dos slides 7 e 8 é um neurônio com 9 entradas: os pesos são os 9 números do filtro
  • Uma rede neural são camadas de neurônios, a saída de uma entrando na próxima. Treinar é a descida do gradiente do slide anterior, mexendo em todos os pesos ao mesmo tempo

O treino também acha filtros

escrito por nós: borda vertical

aprendido: filtro 4 do detector de emoção

  1. Até aqui, quem escolheu os números fomos nós: o 50 da regra e os 9 do filtro.
  2. Embaixo, um dos 32 filtros da primeira camada do detector de emoção que você liga no passo 4. Ninguém digitou esses números: o treino achou.
  3. Compare com o nosso: negativo à esquerda, positivo à direita, e os 9 números somam −0,01. É um detector de borda vertical que também não liga para a luz, e a saída acende nos mesmos lugares.
  4. Machine learning é isso em escala: dar exemplos com a resposta certa e ajustar os números pela descida do gradiente até errar pouco. O detector de emoção aprendeu com o FER2013, um conjunto de 35.887 fotos de rosto com a emoção marcada, e tem 205.129 números ajustados assim.

// [canto externo, canto interno, palpebra de cima, palpebra de baixo]
const OLHO_DIR = [33, 133, 159, 145];
const OLHO_ESQ = [263, 362, 386, 374];

function distancia(a, b) { // distancia entre dois pontos [x, y]
  return Math.hypot(a[0] - b[0], a[1] - b[1]);
}

function aberturaOlho(mesh, olho) { // distancia entre as palpebras, em pixels
  return distancia(mesh[olho[2]], mesh[olho[3]]);
}

// a cada quadro, com o primeiro rosto detectado:
const rosto = human.result.face[0];
const abertura = (aberturaOlho(rosto.mesh, OLHO_DIR) + aberturaOlho(rosto.mesh, OLHO_ESQ)) / 2;

const LIMIAR_RAZAO = 0.20; // razao abaixo disso = olho fechado

function razaoAberturaOlho(mesh, olho) {
  const abertura = distancia(mesh[olho[2]], mesh[olho[3]]);
  const largura = distancia(mesh[olho[0]], mesh[olho[1]]);
  return abertura / largura;
}

// a cada quadro:
const razao = (razaoAberturaOlho(rosto.mesh, OLHO_DIR) + razaoAberturaOlho(rosto.mesh, OLHO_ESQ)) / 2;
if (razao < LIMIAR_RAZAO) {
  olhoFechado = true;
} else if (olhoFechado) {
  piscadas++;
  olhoFechado = false;
}

const EMOCOES = { angry: 'raiva', disgust: 'nojo', fear: 'medo', happy: 'feliz',
                  sad: 'triste', surprise: 'surpresa', neutral: 'neutro' };
let emocaoAtual = '';

function lerEmocao() {
  const rosto = human.result.face[0];
  if (!rosto || !rosto.emotion || rosto.emotion.length === 0) return;
  emocaoAtual = EMOCOES[rosto.emotion[0].emotion]; // maior score primeiro
  escrever(`Emoção: ${emocaoAtual}`, 3);
}

// no drawLoop, a cada quadro:
lerEmocao();

Por dentro · O detector de emoção, camada por camada

  

    

      
entrada: o rosto em 64 × 64, cinza = 4.096 números

      
camada 1: 32 filtros 3 × 3 (os da direita)

      
camada 2: 64 filtros 3 × 3, sobre as 32 saídas da camada 1

      
blocos com 128 e depois 256 canais, 2 reduções de tamanho e 2 atalhos que somam camadas

Decorar × aprender

      
Um modelo grande pode acertar quase 100% das fotos de treino só por decorá-las, e errar muito nas novas (overfitting). É como um teste unitário escrito só para os casos que você já sabe que passam.

Passo 5 · O que é um microcontrolador

  

    

      
    
        
  • Um computador inteiro num chip: processador, memória e entradas/saídas
    • 
        
  • Sem sistema operacional: roda um programa só, para sempre, em laço, como o drawLoop da página
    • 
        
  • Entradas (sensores): botões, acelerômetro, bússola, luz, temperatura, toque, microfone
    • 
        
  • Saídas (atuadores): LEDs, alto-falante, pinos, rádio
    • 
      

    

    

      

        
micro:bit V1micro:bit V2

        
processador16 MHz64 MHz

        
memória do programa256 KB512 KB

        
memória de trabalho16 KB128 KB

      

      
Um notebook com 8 GB tem 65.536 vezes a memória de trabalho do V2 (8 GB ÷ 128 KB). A placa compensa fazendo uma coisa só.

// 01: matriz de LED, 25 LEDs em 5 colunas x 5 linhas (V1 e V2)
basic.showString("Oi!")          // texto rolando

basic.pause(1000)                // espera 1 segundo (em milissegundos)

Passo 5 · Acelerômetro: nível de bolha

  
componente 4 de 13 · V1 e V2

  
Arquivo: passo_5_microbit/makecode/04_acelerometro_nivel.js, colado na aba JavaScript do MakeCode.

  

    
// 04: acelerometro, nivel de bolha (V1 e V2)
// a aceleracao vai de -1023 a 1023 em cada eixo; Math.map converte para a coluna/linha 0 a 4
basic.forever(function () {
    let x = Math.round(Math.constrain(Math.map(input.acceleration(Dimension.X), -1023, 1023, 0, 4), 0, 4))
    let y = Math.round(Math.constrain(Math.map(input.acceleration(Dimension.Y), -1023, 1023, 0, 4), 0, 4))
    basic.clearScreen()
    led.plot(x, y) // o ponto escorrega para o lado mais baixo
    basic.pause(50)
})

    

      
O que é

      
Cada eixo dá um número de -1023 a 1023. Math.map converte essa faixa para a da tela (0 a 4): a mesma ideia de normalizar uma medida, como a razão do olho no dia 1.

      
Na placa

      
Incline a placa: o ponto escorrega para o lado mais baixo.

// 05: bussola (V1 e V2)
// na primeira vez a placa pede calibracao: incline ate acender todos os LEDs
basic.forever(function () {
    let direcao = input.compassHeading() // 0 a 359 graus, 0 = norte
    if (direcao < 45 || direcao >= 315) {
        basic.showString("N")
    } else if (direcao < 135) {
        basic.showString("L")
    } else if (direcao < 225) {
        basic.showString("S")

        basic.showString("O")
    }
})

Um magnetômetro mede o campo magnético da Terra e dá a direção em graus (0 = norte). Ímãs e metais por perto atrapalham.

      
Na placa

      
Na primeira vez, a placa pede calibração: incline até acender todos os LEDs. Depois mostra N, L, S ou O.

Passo 6 · Parte A: receptor, ler linha por linha

  
receptor, trecho 3 de 3

  

    
Arquivo
microbit_receptor.py, escrito no python.microbit.org
Onde
No fim do arquivo
Por quê
Os bytes chegam aos pedaços. O laço junta tudo no buffer, procura o \n, recorta a linha e converte para texto (strip tira um \r). Se a palavra está no dicionário, mostra a carinha.

O while de dentro trata duas linhas que chegaram juntas.

    
  uart.init(baudrate=115200)  # mesma velocidade do navegador (baudRate: 115200)
  display.show(Image.ASLEEP)  # esperando a primeira mensagem
  buffer = b""
+
+ while True:
+     if uart.any():
+         dados = uart.read()
+         if dados:
+             buffer += dados
+         fim = buffer.find(b"\n")
+         while fim != -1:  # pode ter chegado mais de uma linha de uma vez
+             linha = buffer[:fim]
+             buffer = buffer[fim + 1:]
+             texto = str(linha, "utf-8").strip()
+             if texto in IMAGENS:
+                 display.show(IMAGENS[texto])
+             fim = buffer.find(b"\n")
+     sleep(10)

Passo 6 · Parte B: o envio em código

  

    

      
    
        
  • porta e escritor: a porta serial aberta e por onde mandamos bytes
    • 
        
  • desconectar(): fecha a porta antes de conectar de novo
    • 
        
  • o clique no botão pede a porta do micro:bit e abre a 115200
    • 
        
  • enviarEmocao: só envia quando a emoção muda, com \n no fim
    • 
        
  • em lerEmocao(), a cada quadro, chama o envio
    • 
      

      
Resumo, sem os tratamentos de erro. Arquivo: human/demo/video/piscadas.html. O código completo entra nas 6 edições a seguir, de baixo para cima.

    

    
const botao = document.getElementById('conectar');
let porta = null;
let escritor = null;
let ultimaEnviada = '';

async function desconectar() { /* solta o escritor e fecha a porta */ }

botao.onclick = async () => {
  await desconectar(); // clicar de novo reconecta do zero
  porta = await navigator.serial.requestPort({ filters: [{ usbVendorId: 0x0d28 }] });
  await porta.open({ baudRate: 115200 });
  escritor = porta.writable.getWriter();
};

async function enviarEmocao(emocao) {
  if (!escritor || emocao === ultimaEnviada) return; // so quando muda
  ultimaEnviada = emocao;
  await escritor.write(new TextEncoder().encode(emocao + '\n'));
}

// em lerEmocao(), a cada quadro:
enviarEmocao(emocaoAtual);
