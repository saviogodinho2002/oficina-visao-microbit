# Gabarito do passo 2

`piscadas.html` é o arquivo completo como ele fica no fim do passo 2.

**Não abra este arquivo daqui** (nem com duplo clique, nem por um servidor apontado para a pasta da oficina). Ele carrega a biblioteca de `../../dist/human.esm.js` e os modelos de `../../models`, caminhos que só existem dentro do repositório `human`. Aberto daqui, o console mostra `blocked by CORS policy` ou `404` e a tela fica preta.

Para usar:

```bash
# copiar para dentro da demo do human (rodar na pasta que contém human/ e oficina-visao-microbit/)
cp oficina-visao-microbit/passo_2_piscadas_distancia/gabarito/piscadas.html human/demo/video/
# no Windows: copy oficina-visao-microbit\passo_2_piscadas_distancia\gabarito\piscadas.html human\demo\video\

# servir a pasta human (se ainda não estiver rodando)
cd human
npx serve
```

Depois abrir <http://localhost:3000/demo/video/piscadas.html> e seguir a partir do passo seguinte com a turma.
